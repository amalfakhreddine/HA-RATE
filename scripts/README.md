# Admin Password Setup

## Problem
The admin login requires a bcrypt-hashed password, not a plain text password. If you're getting "Invalid credentials" even with the correct password, it means your `ADMIN_PASSWORD_HASH` secret is not properly hashed.

## Solution

### Step 1: Generate Your Password Hash

Run this command in the Shell with your desired password:

```bash
tsx scripts/generate-admin-password.ts YourPasswordHere
```

**Example:**
```bash
tsx scripts/generate-admin-password.ts MySecureAdmin123
```

### Step 2: Copy the Generated Hash

The script will output a bcrypt hash that looks like this:
```
$2b$10$abc123def456...
```

### Step 3: Update Your Secrets

1. Go to **Tools → Secrets** in Replit
2. Find the secret named `ADMIN_PASSWORD_HASH`
3. **Replace** its value with the hash you just generated
4. **Save** the secret

### Step 4: Restart Your Application

Click the **Restart** button or refresh the page to apply the new password.

### Step 5: Login

Now you can login to the admin panel at `/admin-login` using:
- **Username**: Your `ADMIN_USERNAME` (e.g., BITMMP)
- **Password**: The plain text password you used to generate the hash (e.g., MySecureAdmin123)

---

## Environment Variables Required

Make sure you have both secrets set:

- `ADMIN_USERNAME` - Your admin username (plain text)
- `ADMIN_PASSWORD_HASH` - The bcrypt hash generated by this script

## Security Notes

- ✅ Never commit the plain text password to your repository
- ✅ The bcrypt hash is safe to store in environment variables
- ✅ Each hash is unique, even for the same password
- ✅ Use a strong password with letters, numbers, and special characters
